# 输出尺寸预设

## 小红书图文笔记

- 画幅：3:4 竖版
- 目标尺寸：1080×1440px
- 用途：小红书信息流图文笔记，优先保证移动端占屏和首屏可读性
- 构图：主体尽量集中在中上部；标题字号大、层级少；人物脸、产品和关键文字保持约 10% 安全区
- 避免：过多细小文字、横向长句、底部堆放关键内容

提示词第一行固定写：

```text
3:4 竖版构图，输出尺寸 1080×1440px
```

## 微信公众号头条头图（推送列表封面）

- 画幅：2.35:1 横版
- 目标尺寸：900×383px
- 用途：公众号推送列表头条封面，适合横向卡片展示
- 构图：将标题区、人物区或产品区横向分层；标题不要塞满画面；关键主体不要贴上下边缘
- 避免：把 3:4 海报直接横向裁切、把人物脸放在边缘、把所有信息压缩成小字

提示词第一行固定写：

```text
2.35:1 横版构图，输出尺寸 900×383px
```

如果生图工具不支持 900×383px，可按 2.35:1 生成更高分辨率版本，再等比例缩放到 900×383px；不要改变画幅比例。

## 两套都生成

用户要求同时生成两种平台尺寸时，分别输出两套完整提示词。可以复用人物、标题和配色，但必须重新安排构图，不要仅替换第一行尺寸。
