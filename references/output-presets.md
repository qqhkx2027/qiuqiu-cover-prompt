# 平台输出预设

平台决定默认风格；用户明确给出尺寸时，以用户尺寸为准，但保留平台对应的构图逻辑。

## 微信公众号头条头图：星露谷像素风

- 平台：微信公众号推送列表头条封面
- 风格：秋秋同款星露谷像素风
- 画幅：2.35:1 横版
- 推荐尺寸：900×383px
- 构图：温暖像素木屋/工作室，标题区、人物区和工作台区横向分层
- 重点：适配公众号列表卡片裁切，标题和人物不要贴边

提示词第一行固定写：

```text
2.35:1 横版构图，输出尺寸 900×383px，秋秋同款星露谷像素风
```

## 视频号、B站横版封面：抠像风格

- 平台：视频号或 B 站横版视频封面
- 风格：秋秋同款抠像风格
- 画幅：16:9 横版
- 推荐尺寸：1920×1080px
- 构图：人物或产品大比例抠像，主体占画面约 45%—65%，标题放在留白侧
- 背景：简洁纯色、渐变、纸张或轻纹理，不使用复杂场景抢主体
- 重点：缩小成视频列表卡片后，人物轮廓和标题仍然清楚

提示词第一行固定写：

```text
16:9 横版构图，推荐输出尺寸 1920×1080px，秋秋同款抠像风格
```

## 抖音、快手、小红书竖版封面组：抠像风格

三个平台共用“秋秋同款抠像风格”，只按平台比例输出不同画幅。

- 平台：抖音或快手竖版视频封面（竖版抠像组）
- 风格：秋秋同款抠像风格
- 画幅：9:16 竖版
- 推荐尺寸：1080×1920px
- 构图：人物抠像居中或偏侧，标题分 2—4 行放在安全区，适配全屏首屏
- 背景：简洁色块、渐变或轻纹理，突出人物表情、手势和道具
- 重点：顶部和底部预留界面遮挡安全区，不把关键文字放在边缘

提示词第一行固定写：

```text
9:16 竖版构图，推荐输出尺寸 1080×1920px，秋秋同款抠像风格
```

### 小红书图文笔记适配

- 平台：小红书图文笔记封面（竖版抠像组）
- 风格：秋秋同款抠像风格
- 画幅：3:4 竖版
- 推荐尺寸：1080×1440px
- 构图：人物或产品抠像占据中上部，标题大而少，适合信息流首屏阅读
- 背景：简洁色块、纸张、轻纹理或少量主题道具
- 重点：不堆放细小文字，人物脸、产品和标题保持约 10% 安全区

提示词第一行固定写：

```text
3:4 竖版构图，输出尺寸 1080×1440px，秋秋同款抠像风格
```

## 抠像风格的共同规则

- 人物或产品完整抠出，保留自然发丝和轮廓，不让边缘溶解。
- 可以加入轻微投影、描边、贴纸边缘或纸张撕边，但不要变成复杂海报拼贴。
- 人物身份参考只负责五官、发型、肤色和身份一致性；不照搬原照片背景。
- 标题使用粗体无衬线中文字体，必要时加描边或阴影，确保缩小后仍可读。

## 同时生成多种平台

用户要求同时生成多个平台时，分别输出完整提示词。可以复用人物、标题和配色，但必须重新安排构图：公众号使用像素场景，其他平台使用抠像布局，不要只替换第一行尺寸。
