# 十种构图模式

平台基础视觉仍然有效：公众号套用星露谷像素质感，视频号/B站及抖音/快手/小红书套用抠像质感。以下模式只决定构图、人物比例、产品位置和标题层级。

## 1. 深色渐变风

- 适合：科技、AI、教程、观点类主题。
- 画面：深色渐变背景，人物居中或偏下，超大标题覆盖人物后方，少量主题图标点缀。
- 关键句：`深色渐变背景，人物半身居中，超大中文标题位于人物后方，被人物局部遮挡，前景少量悬浮图标，形成高对比层次。`

## 2. 纯色扁平风

- 适合：清单、入门、生活方式和轻教程。
- 画面：低饱和纯色背景，人物干净抠图，主体道具近大远小，标题被主体局部遮挡。
- 关键句：`纯色扁平背景，人物抠像，主体道具以近大远小透视推向镜头，背景低饱和、主体高饱和，标题与主体形成遮挡层次。`

## 3. 产品主视觉风

- 适合：有 UI 截图、产品图或工作台界面的内容。
- 画面：产品/UI 占 60%—70%，人物缩小到约 20%—25%，做指向、展示或引导动作。
- 关键句：`产品或 UI 截图占画面约 65%，清晰锐利，人物偏一侧偏下做引导手势，背景简洁，让产品成为绝对主角。`

## 4. 对比卡片风

- 适合：前后对比、方法对比、错误与正确对比。
- 画面：人物双手分别持两张卡片，前景卡片大且明亮，后景卡片小且暗，形成透视对比。
- 关键句：`两张内容明确对比的卡片一前一后，前景卡片大而明亮、后景卡片小而暗，人物双手分别托住卡片，形成强烈近大远小透视。`

## 5. 极简留白风

- 适合：观点、金句、品牌和标题驱动内容。
- 画面：留白超过 60%，人物仅占 20%—25%，标题是唯一主视觉锤。
- 关键句：`大面积浅色留白，人物位于角落且体量较小，超大标题占据留白区主体，元素极少，版面克制、呼吸感强。`

## 6. 海报拼贴风

- 适合：素材丰富、案例集合、多场景叙事。
- 画面：前景主素材、中景人物、后景辅助素材，明确遮挡和投影关系。
- 关键句：`多张素材按前景、中景、后景分层叠加，主素材最大且清晰，人物与素材互相遮挡，背景素材轻微虚化，制造海报拼贴纵深。`

## 7. 人物侧置留白风

- 适合：教程、推荐、个人观点和品牌内容。
- 画面：人物偏左或偏右占 25%—35%，对侧 60% 以上留给标题，人物视线指向标题。
- 关键句：`人物偏置一侧，占画面宽度约 30%，身体和视线朝向对侧留白区，对侧用大标题填充，版面大气、清晰。`

## 8. 背影构图风

- 适合：成长、出发、改变和愿景类内容。
- 画面：人物背对镜头，不露脸，前方有目标场景或主视觉，文字宽松放置。
- 关键句：`人物背对镜头，只见后脑、肩膀和背部，朝向前方目标或主视觉，画面有开阔纵深，标题在上方或两侧留白区。`

## 9. 局部出镜风

- 适合：产品、UI、工作台、工具展示；产品或文字必须是绝对主角。
- 画面：产品/UI 占约 60%—75%，只露手、半脸或侧脸，占边缘 15%—25%，动作指向或触碰产品。
- 关键句：`产品或 UI 占画面约 65%，清晰锐利；画面边缘只露一只手、半张脸或侧脸，人物局部做指向、触碰或展示动作，只作为见证者，不得喧宾夺主。`

## 10. 正面对视风

- 适合：警示、态度、强情绪和直接推荐。
- 画面：人物正面居中直视镜头，标题上下夹住脸部，不遮挡眼睛和嘴巴。
- 关键句：`人物正面半身直视镜头，情绪明确，标题分置脸部上下形成框架，文字不遮挡眼睛和嘴巴，背景与人物形成高对比。`

## 模式变量

生成完整提示词时补齐：人物表情、动作、主体材质与占比、前中后景关系、背景色调、字体风格、字体效果和安全区。不要把模式关键关系替换成泛泛的“高级”“有冲击力”。
