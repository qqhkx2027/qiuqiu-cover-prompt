# 秋秋公众号封面 生成前检查清单

- [ ] 已完整读取文章正文，主题、钩子、核心数字、真实素材都标出
- [ ] 封面只保留 1 个最强钩子 + 1 个主标题 +（可选）1 句补充
- [ ] 全文案 20~35 汉字，不超过 3 组文字
- [ ] 主标题在讲正文真正主题（不是随便挑一个词）
- [ ] 是否提供秋秋真人参考照：有 -> 用 80% 真人 + 20% 像素；无 -> 不画人物，右侧留空
- [ ] 是否提供真实产品 / Logo / 旅行照：有 -> 原位使用；无 -> 用文字名或留空，不编造
- [ ] 比例写入 2.35:1（推荐 1880x800）
- [ ] 品牌风格：暖木色复古像素工作台，紫 / 粉 / 奶油黄，明亮不暗
- [ ] 标题是视觉焦点，不被人物或道具遮挡
- [ ] 中文字逐字正确，提示词里重复“逐字正确、无错字、无漏字”
- [ ] 已提醒用户生成后逐字检查标题，必要时重跑

## 生成后检查

- [ ] 实际比例是 2.35:1 横版？
- [ ] 没有出现未授权的人、Logo、产品或文字？
- [ ] 真人（如有）没有被卡通化？
- [ ] 真实素材（如有）未被重绘或替换？
- [ ] 画面整体明亮温暖，不是暗色科技风？
- [ ] 中文标题无错字漏字？
- [ ] 用户要求“只改某处”时，其余部分未动？
