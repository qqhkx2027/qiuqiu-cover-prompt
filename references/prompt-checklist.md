# 秋秋公众号封面验收清单

## 生成前

- [ ] 已读取完整文章；主题、点击理由、核心数字/结果/冲突有正文依据
- [ ] 已确认模式：`GENERATE`、`COMPOSITE` 或 `LOCAL_EDIT`
- [ ] 已建立 `reference_manifest`；角色不依赖图片序号
- [ ] 只索取文章确实需要的产品、Logo、截图或旅行照
- [ ] 文案已确认；用户直接给出的文案未被改写
- [ ] 总文字约 20～35 个汉字，未塞功能清单
- [ ] 提示词写明 2.35:1、推荐 1880×800、留出标题安全区、不得添加未授权文字
- [ ] 有真实/原图/保持不变要求时未使用全画面重绘
- [ ] 计划使用 `scripts/render_cover_text.py` 后期压字，或已记录不使用的原因

## 生成后

- [ ] 实际尺寸和比例正确
- [ ] 只看封面能推出正文主题
- [ ] 中文由后期脚本压字并逐字复核；重点数字无误
- [ ] 真人（如有）仍像秋秋，未卡通化或换脸
- [ ] 产品、Logo、包装、旅行照（如有）未被重绘、换色或替换
- [ ] 标题、人物、产品没有互相遮挡；画面明亮温暖
- [ ] 没有未授权人物、产品、Logo、地点或装饰文字
- [ ] 局部编辑只改了用户点名区域

不确定的项目标记「待确认」，不要用“看起来应该正确”代替检查。
