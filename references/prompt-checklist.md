# 封面提示词检查清单

生成前：

- 是否已确认输出类型：小红书 3:4 竖图，还是微信公众号 2.35:1 横图？
- 是否已把目标尺寸写入提示词（1080×1440px 或 900×383px）？
- 是否已确认文章核心主题、目标读者和视觉化卖点？
- 标题是用户指定的正式标题，还是可由模型提炼的短标题？长标题是否决定保留原文并通过换行解决？
- 是否已选一种构图风格，而不是混用多种风格？
- 是否为每张参考图分配了明确角色（人物身份、旧封面风格、产品/UI、Logo）？
- 是否清楚写出参考图的允许用途与禁止照搬部分？
- 是否具体写了人物动作、主体大小和前中后景关系？
- 是否已经把用户明确给出的像素风、口罩、大头等要求写进提示词，而不是重新询问？
- 用户是否要求直接跑图？若要求，是否先展示提示词并准备检查生成结果？

生成后：

- 第一行是否与所选预设一致，并包含准确尺寸？
- 小红书是否保持 3:4、1080×1440px；微信公众号是否保持 2.35:1、900×383px？
- 标题是否用中文引号圈出并逐字保留？
- 长标题是否采用 2—4 行安全换行，没有擅自改字或添加副标题？
- 关键元素是否在约 10% 安全区内？
- 是否明确禁止额外文字、乱码、错别字、水印和 Logo？
- 人脸参考是否只用于身份一致性，旧封面是否只用于风格/构图参考？
- 是否提醒用户逐字检查中文，必要时重新生成？
- 如果图像工具失败，是否明确说明没有生成成品并保留可复制提示词？
