# 标题与参考图规则

## 标题处理

1. 用户给出的文章正式标题视为最终文案，默认逐字保留。
2. 长标题先拆成语义组，再换行；不要通过删字、换同义词或添加副标题来降低长度。
3. 推荐的拆分顺序：品牌/产品名 → 核心方法 → 结果或受众。例如：

   ```text
   WorkBuddy新手教程
   用提问方法
   0基础搭建专属你的AI工作台
   ```

4. 生成模型对中文文字的准确率有限：提示词要重复“标题逐字正确、无错别字、无漏字”，生成后仍要逐字检查。若标题准确性很重要，优先让模型生成无字背景，再在编辑器中叠加文字。
5. 公号封面默认保留四边约 10% 安全区，并考虑手机端裁切；标题不得贴边、压脸或被道具遮挡。

## 参考图角色

先按内容角色编号，再写进提示词：

| 角色 | 用法 | 不应做什么 |
|---|---|---|
| 人物身份图 | 保持五官、发型、肤色、身份一致 | 不照搬原背景、姿势或原图文字 |
| 旧封面图 | 借鉴色彩、像素质感、层级和构图 | 不复制旧封面的标题、Logo 或全部画面 |
| 产品/UI 图 | 作为主视觉或道具，写清占比和朝向 | 不凭空补看不清的界面文案 |
| Logo/图标图 | 只在用户要求时保留品牌识别 | 不让模型自发添加 Logo 或水印 |

参考图超过一张时，在提示词中显式写出“图 1 只用于……；图 2 只用于……”。如果同一张图兼任多个角色，说明优先级，避免身份和风格互相污染。
