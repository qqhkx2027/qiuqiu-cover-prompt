# 秋秋同款星露谷像素风

当前版本只使用这一套风格，不列出或询问其他风格。

## 核心视觉

- 温暖的星露谷式乡村木屋/工作室场景
- 16-bit 或 32-bit 像素插画，清晰像素块、细腻木纹、植物和小道具
- 木色、橙金色、紫色、蓝紫色、绿色为主色，饱和但不刺眼
- 柔和的窗光与蓝紫色阴影，氛围友好、鼓励新手、有生活感
- 真人脸参考只保持人物身份；人物可以像素化、戴口罩、做适度大头特效
- 不使用 3D 渲染、照片写实、廉价霓虹、数据流、粒子爆炸或过度科技背景

## 小红书 3:4 构图

```text
3:4 竖版构图，输出尺寸 1080×1440px。采用秋秋同款星露谷像素风：温暖的像素木屋工作室，木墙、窗户、绿植、书架、台灯、书桌和笔记本电脑。人物参考图1的五官、发型和身份特征，保持人物一致性；人物位于画面右侧或中下部，做自然的大头特效，标题位于上方独立木牌或标题板内。前景是书桌和少量道具，中景是人物与电脑，后景是窗户、书架和植物。标题和人脸距四边至少约10%，适配手机信息流首屏阅读。
```

## 微信公众号 2.35:1 构图

```text
2.35:1 横版构图，输出尺寸 900×383px。采用秋秋同款星露谷像素风：将温暖的像素木屋工作室横向展开，标题区、人物区和工作台区分层排列。人物参考图1的五官、发型和身份特征，保持人物一致性；人物放在画面右侧或左侧，标题放在对侧的木牌/像素标题板内。前景为木桌和道具，中景为人物与电脑，后景为窗户、书架和植物。避免把竖版海报直接裁切成横图，标题和人脸距四边至少约10%，适配公众号推送列表卡片。
```

## 标题与负面约束

在任一构图骨架中加入：

```text
中文标题“[标题]”必须逐字正确，使用粗体像素中文字体，按画幅分成 2—4 行；不添加副标题、Logo、水印、英文标语或其他文字。避免乱码、错别字、低清马赛克、额外人物、霓虹灯、数据流、粒子特效和过度装饰。
```
