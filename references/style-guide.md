# 秋秋微信公众号封面视觉规范

## 固定系统

| 维度 | 规则 |
| --- | --- |
| 画布 | 2.35:1；优先 1880×800、1645×700 或 1410×600 |
| 场景 | 暖木色书房/工作台、木架、窗光、桌面道具 |
| 质感 | 复古像素游戏 UI；人物和真实物品保留真实感 |
| 人物 | 约 80% 真人感 + 20% 像素融合；无身份图不虚构 |
| 主色 | 深暖木棕、蜂蜜木、奶油米 |
| 强调色 | 紫、桃粉、奶油黄；辅以蓝灰、墨绿、焦糖橙 |
| 明度 | 阳光、暖窗光、暖黄高光；禁止整图阴暗 |

避免全粉、荧光色、冰蓝科技感、黑色赛博感、大面积纯白和细宋体。

## 构图

- 默认：左侧 55%～65% 标题，右侧 30%～40% 真人或留白，下方真实主体。
- 产品型：标题左、产品中、真人右。
- 旅行式：标题中、真实旅行照做路线/Polaroid、真人右。
- 多产品：主标题在上，真实 Logo 或文字名牌横排；每个产品最多一句标签，画面拥挤时删标签。

## 标题

最多三组：小钩子（2～8 字）、主标题（4～10 字）、可选补充。整页约 20～35 个汉字。用粗方像素字、清晰描边/投影；主标题最大，数字可用玫红或奶油黄强调。

标题回答“为什么点开”，不要堆价格、参数、功能清单或受众标签。除非正文确认，否则不添加“学生党”“大学生”等身份判断。

## 身份真实

当使用内置身份参考（图 1）时：

- 保留黑色长发、脸型和五官比例、眼睛特征、肤色、年龄感。
- **默认保留原参考图的口罩**；只有用户明确要求才摘除。
- 禁止为了“更漂亮/更自然/更像网红/更适合封面”而换脸、削下颌、过度美颜、娃娃脸化、完全像素化。
- 不复制原图的背景、姿势、配饰或文字。

## 内置参考图与真实素材

- 图 1 只提供身份特征：脸、黑发、口罩、发型、肤色、年龄感。不要复制其他人任何背景或文字。
- 图 2 只提供风格：暖木像素、光线、配色、文本层级与桌面关系。不要复制其文案、人物、Logo、电脑或具体产品。
- 用户提供的产品、包装、Logo、旅行照优先原位使用；不改形状、颜色、品牌，不凭空增加同类物品。
