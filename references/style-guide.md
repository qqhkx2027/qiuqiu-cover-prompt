# 秋秋同款平台风格

平台决定风格，不要求用户在多套风格之间反复选择：

| 平台 | 默认风格 |
| --- | --- |
| 微信公众号横版头图 | 星露谷像素风 |
| 视频号、B站横版封面 | 抠像风格 |
| 抖音、快手、小红书竖版封面 | 抠像风格 |

## 公众号横版：星露谷像素风

### 核心视觉

- 温暖的星露谷式乡村木屋/工作室场景
- 16-bit 或 32-bit 像素插画，清晰像素块、木纹、植物和小道具
- 木色、橙金色、紫色、蓝紫色、绿色为主色，饱和但不刺眼
- 柔和窗光与蓝紫色阴影，氛围友好、有生活感
- 真人脸参考只保持人物身份；人物可以像素化、戴口罩、做适度大头特效
- 不使用 3D 渲染、照片写实、廉价霓虹、数据流、粒子爆炸或过度科技背景

### 构图骨架

```text
2.35:1 横版构图，输出尺寸 900×383px，秋秋同款星露谷像素风。将温暖的像素木屋工作室横向展开，标题区、人物区和工作台区分层排列。人物参考图1的五官、发型和身份特征，保持人物身份一致；人物位于画面左侧或右侧，标题放在对侧的木牌/像素标题板内。前景为木桌和少量道具，中景为人物与电脑，后景为窗户、书架和植物。标题和人脸距四边至少约10%，适配公众号推送列表卡片裁切，避免把竖版海报直接裁成横图。
```

## 视频号、B站横版：抠像风格

### 核心视觉

- 人物或产品完整抠像，主体占画面约 45%—65%
- 保留自然发丝、轮廓和手部，不让边缘溶解或出现白边
- 背景使用简洁纯色、柔和渐变、纸张或轻纹理
- 标题使用粗体无衬线中文字体，可加描边、投影或贴纸边缘
- 画面要在视频列表缩略图中保持人物表情和标题清楚
- 不使用复杂摄影棚、密集科技 UI、无意义小字和过度拼贴

### 构图骨架

```text
16:9 横版构图，推荐输出尺寸 1920×1080px，秋秋同款抠像风格。将图1人物完整抠出，保留五官、发型、肤色和身份特征，人物占画面约一半，放在左侧/右侧主体区；另一侧留出干净标题区。背景使用简洁渐变色块、轻纸张纹理和少量与文章主题相关的道具。人物边缘清晰，加入自然投影或轻微贴纸描边。标题使用粗体无衬线中文字体，逐字正确，缩小为视频列表卡片后仍清楚。
```

## 抖音、快手、小红书竖版：抠像风格

三者共用同一套“秋秋同款抠像风格”；仅根据平台比例调整主体位置、标题换行和安全区：抖音/快手使用 9:16，小红书使用 3:4。

### 构图骨架

```text
9:16 竖版构图，推荐输出尺寸 1080×1920px，秋秋同款抠像风格。人物或产品完整抠像，主体位于画面中上部或中间，保持脸部、标题和关键道具在安全区内。背景使用简洁色块、渐变、纸张纹理或少量主题道具；人物可以做自然的大头特效、夸张表情和清晰手势。标题使用粗体无衬线中文字体，分成2—4行，加入适度描边或阴影，避开顶部和底部可能被平台界面遮挡的区域。
```

### 小红书 3:4 适配

在同一套抠像风格上，使用 3:4 竖版构图，输出尺寸 1080×1440px。人物或产品完整抠像，占据画面中上部，标题放在人物旁侧或上方的干净区域，适配小红书信息流首屏；标题大而少，避免细小文字堆叠。

## 参考图和负面约束

人物、旧封面、产品截图和 Logo 必须分配不同角色：

```text
图1只用于人物身份参考，不照搬图1的背景、姿势或文字；图2只用于风格、色彩或构图参考；图3只用于产品或界面道具参考。中文标题“[标题]”必须逐字正确，不添加副标题、Logo、水印、英文标语或其他文字。
```

抠像风格额外禁止：主体边缘溶解、白边、错误肢体、重复人物、复杂背景抢主体、密集小字和过度装饰。
